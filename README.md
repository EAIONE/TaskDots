# TaskDots · 任务记录（macOS 屏幕边缘待办便签）

一款为设计工作场景打造的 macOS 桌面任务便签工具：常驻屏幕边缘、四象限优先级、返修次数统计、截止提醒与重复任务，附带书籍字号对照等排版小工具。

## 下载安装

1. 前往 [Releases 页面](https://github.com/EAIONE/TaskDots/releases) 下载 `TaskDots.zip`
2. 解压后把 **TaskDots.app** 拖入「应用程序」文件夹
3. 首次打开若提示「无法验证开发者」：在 Finder 中**右键点击 App → 打开 → 再点「打开」**（只需一次）
4. 建议在设置中开启「登录时启动」，开机即用

## 快速上手

1. **添加任务**：在底部输入框输入任务名称，回车即加入待办（最多同时 30 条）
2. **设优先级**：任务默认归入「重要不紧急」，点击任务卡的优先级色条可改到四个象限之一
3. **完成 / 删除**：点卡片左侧对勾标记完成；右键菜单或展开卡片中可删除；误操作可点提示条上的「撤销」

## 功能说明

### 优先级四象限
- 紧急重要（红）/ 重要不紧急（橙）/ 紧急不重要（黄）/ 不急不重（绿）
- 卡片左侧四色条显示所属象限；顶栏四色筛选按钮可点选只看某一类，全部点亮 = 显示全部

### 返修次数
- 待办卡片下方显示「返修次数 0」，**点击一次 +1**，同时整卡出现绿色边框表示本次已提交
- 绿色边框从点击起保留 4 小时，到期自动消失；再次点击重新计时
- 次数与最近提交时间保存在本机，重启不清零

### 截止日期与提醒
- 给任务设截止日期后，卡片显示「今天截止 / 明天截止 / 截止 x月x日」，过期标红
- 提醒可选：不提醒 / 当天 / 提前1天 / 提前2天，到点发系统通知

### 重复任务
- 支持每天、工作日（周一至周五）、每周指定几天、每月最后一个周 X（遇节假日提前）四种规则
- 到期自动生成当日待办

### 排列与收纳
- **拖动卡片**可手动排序；排序菜单可在「手动排序 / 默认排序（按优先级）」间切换
- 右键菜单可「置顶」；拖动整个面板到屏幕左/右边缘可**停靠**，双击停靠面板展开/收起
- 标题栏拖到屏幕边缘也可收纳；位置、展开状态都会记住

### 搜索与筛选
- 顶部搜索框按名称实时过滤；可与四色筛选叠加，点「重置筛选」一键清空

### 已完成任务与撤销
- 工具栏对勾图标查看已完成任务，可从中再次加入待办
- 最近一次完成/删除操作可通过状态条「撤销」恢复

### 附带小工具（排版向）
- **书籍尺寸 · 字号对照**：常用成品尺寸对应的推荐字号速查
- **字号倍率表**：字号倍率换算参考

### 摸鱼语录
- 面板随机显示一条打工人语录，可「换一句 / 收藏 / 不喜欢删除」，收藏列表可随时查看

## 数据存储

所有数据保存在本机（任务、返修记录、设置、语录收藏），卸载前如需备份请备份用户数据目录。应用不联网上传任何数据。

## 从源码构建

```bash
swiftc main.swift -o TaskDots
```

或在 Xcode 新建 macOS App 项目后，将 `main.swift` 与 `AppIcon.icns` 加入项目构建。要求 macOS 13+。
