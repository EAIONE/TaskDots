# TaskDots 任务记录（macOS 菜单栏待办应用）

一个用 SwiftUI 编写的 macOS 任务记录小工具，支持四象限优先级分类与返修次数统计。

## 主要功能

- **四象限优先级**：紧急重要 / 重要不紧急 / 紧急不重要 / 不急不重，左侧四色重要程度条
- **返修次数统计**：待办卡片下方显示「返修次数 0」，点击次数 +1 并显示绿色整卡边框表示本次已提交
  - 绿色边框从最近一次点击起保留 4 小时，到期自动消失
  - 次数与最近提交时间保存在本机，重启不清零
- 点击任务名称可展开编辑
- 菜单栏常驻，支持系统通知

## 构建方法

```bash
swiftc main.swift -o TaskDots
```

或在 Xcode 中新建 macOS App 项目后，将 `main.swift` 与 `AppIcon.icns` 加入项目构建。
